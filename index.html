Keyboard Shortcuts

Help & UI

  • ? - Show/Hide this help
  • h - Show/Hide UI
  • g - Toggle Grid Dialog
  • o - Toggle OSD
  • e - Toggle Edit Mode

Image Operations

  • i - Invert image
  • t - Toggle transparency
  • r - Reset view & threshold

Adjust Mode

  • d - Reset pan
  • → / ← - Zoom in/out
  • 1 - Fit both
  • 2 - Fit width
  • 3 - Fit height
  • CMD+s - Save image

Edit Mode

  • p - Paint tool
  • c - Crop tool
  • x - Toggle erase (Paint)
  • BKSP / DEL - Clear paint
  • → / ← - Brush size
  • CMD+Click - Draw line

Global

  • ↑ / ↓ - Adjust threshold
  • CMD+c - Toggle autocrop
