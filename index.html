Monochromifier

Convert color images to high-contrast monochrome using an adjustable threshold.

Basic Usage

  • Drop or click to load an image onto the canvas
  • Use ↑ / ↓ to adjust the threshold
  • Press e to enter edit mode (paint & crop)
  • Press ? to view all keyboard shortcuts

Monochromifier

Keyboard Shortcuts

Help & UI

  • ? - Show/Hide this help
  • h - Show/Hide UI
  • g - Toggle Grid Dialog
  • o - Toggle OSD
  • e - Toggle Edit Mode

Image Operations

  • i - Invert image
  • t - Toggle transparency
  • r - Reset view & threshold

Adjust Mode

  • d - Reset pan
  • → / ← - Zoom in/out
  • 1 - Fit both
  • 2 - Fit width
  • 3 - Fit height
  • CMD+s - Save image

Edit Mode

  • p - Paint tool
  • c - Crop tool
  • x - Toggle erase (Paint)
  • r - Reset crop (Crop)
  • BKSP / DEL - Clear paint
  • → / ← - Brush size
  • CMD+Click - Draw line

Global

  • ↑ / ↓ - Adjust threshold
  • CMD+c - Toggle autocrop
